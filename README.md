# Программа для работы с числами

Программа на Python: ввод 5 целых чисел, вывод исходного массива,
а также максимума, минимума и суммы элементов.

## Запуск

python3 main.py

## Пример работы

Введите число: 3
Введите число: 7
Введите число: 1
Введите число: 9
Введите число: 4
Исходный массив: [3, 7, 1, 9, 4]
Максимальное число: 9
Минимальное число: 1
Сумма: 24
